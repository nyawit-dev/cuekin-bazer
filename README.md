# #CuekinBuzzer 🇮🇩

> **Diam bukan berarti buta. Cuek bukan berarti setuju.**
> **Kalau kebijakan bagus, ngapain butuh ribuan akun buat tepuk tangan?**

Gerakan digital Indonesia untuk melawan buzzer, hoaks, misinformasi, dan pengalihan isu — bukan dengan debat kusir, tapi dengan **mengatur ulang engagement**: berhenti memberi panggung ke konten provokatif, dan mengalihkan dukungan ke konten yang menyuarakan kepentingan publik berbasis fakta.

> **Catatan:** Ini situs edukasi independen. Bukan akun resmi Windah Basudara, bukan afiliasi pemerintah, bukan partai. Semua klaim faktual di halaman ini merujuk ke pemberitaan sumber tepercaya (daftar di bawah). Kalau ada yang keliru, buka Issue / Pull Request.

## 1. Fakta Singkat ( hasil riset internet )

### 1.1 Kapan & siapa yang menyuarakan

- **5 November 2026** — kreator konten / streamer Windah Basudara mengunggah pesan berjudul **“#cuekinbuzzer — Belajar dari Brasil”** di Instagram pribadinya.
- Kampanye langsung menyebar: menurut KOMBI.ID, **belum genap 24 jam** unggahan itu sudah >576 ribu like, ~7 ribu komentar, dan 171 ribu repost.
- Tagar `#CuekinBuzzer` ikut dipakai luas oleh warganet dan diliput Kompas, Katadata, Suara.com, Akurat, Mojok, IDN Times, RRI, dan Good News From Indonesia.

### 1.2 Apa itu buzzer dalam konteks ini

Buzzer = akun atau jaringan akun yang menyebarkan narasi tertentu secara terkoordinasi, dirancang untuk **memancing emosi, perdebatan, dan konflik**.

Mesinnya sederhana: algoritma platform membaca **semua** sentuhan — like, komentar, share, repost, quote, kunjungan profil, berhenti menonton — sebagai sinyal “konten ini relevan”, lalu menyebarkannya lebih jauh.

Artinya: **membalas buzzer dengan marah = membayar mereka dengan engagement.** Kita yang capek, mereka yang viral.

### 1.3 Belajar dari Brasil: Janonisme

Gerakan ini terinspirasi dari **Janonisme / *Janonismo Cultural*** — pendekatan komunikasi politik digital yang dipopulerkan politikus Brasil **André Janones**.

Di Brasil, strategi ini dikaitkan dengan kemenangan Luiz Inácio Lula da Silva, salah satunya lewat kanal WhatsApp “Laskar Lula”: pendukung diberi **misi harian yang jelas** — jangan layani provokasi lawan, sebar konten siap-pakai berbasis fakta ke grup keluarga/kerabat, dan bangun jejaring dukungan yang terkoordinasi.

Inti yang dibawa ke Indonesia:

1. **Hentikan engagement ke buzzer.**
2. **Tingkatkan engagement ke konten pro-rakyat yang terverifikasi.**

### 1.4 Dua prinsip utama #CuekinBuzzer

| Prinsip | Praktiknya |
|---|---|
| **1. Stop engagement ke buzzer** | Jangan like, komentar, share, repost, quote, screenshot untuk dibalas, kirim link ke grup, atau debat — termasuk pakai akun palsu. |
| **2. Alihkan ke kepentingan publik** | Like, komentar, simpan, tonton sampai selesai, repost, dan kirim link konten berbasis fakta: karhutla & dampaknya, dampak kebijakan publik, isu sosial, dll. |

### 1.5 Panduan “Boleh / Jangan” (dari unggahan Windah, dirangkum Katadata)

**BOLEH**
- Abaikan / scroll lewat tanpa interaksi — algoritma membaca konten yang dilewati tanpa disentuh sebagai konten tak relevan.
- Blokir akun buzzer untuk mengurangi distribusi kontennya.
- Buat **konten tandingan mandiri**: bantahan berbasis data, kronologi, dan sumber primer — tanpa mengulang provokasi atau menyerang identitas penyebar.
- Perkuat konten akurat & terverifikasi (like, share, simpan, tonton penuh).
- Bangun jejaring / grup (mis. WhatsApp) untuk menyepakati materi dan saling mendukung engagement konten pro-rakyat.
- Blokir + report untuk pelecehan, ancaman, doxing, penipuan, atau intimidasi terkoordinasi.

**JANGAN**
- Screenshot konten buzzer lalu diunggah ulang — penonton penasaran akan datang ke akun aslinya (tetap dihitung interaksi).
- Report asal-asalan — report hanya untuk pelanggaran nyata platform.
- Komentar dulu baru blokir — komentar sudah tercatat sebagai engagement.
- Balas lalu hapus — engagement sudah terlanjur tercatat.
- Debat di kolom komentar buzzer, bahkan dengan akun palsu.
- Bagikan link konten buzzer ke grup “buat bahan hujatan” — tetap memperluas jangkauan mereka.
- Like / save / follow / quote konten buzzer.

### 1.6 Disclaimer penting

“Cuekin” bukan berarti membiarkan misinformasi beredar. Koreksi tetap perlu — tapi lewat **unggahan mandiri berbasis data dan sumber primer**, bukan lewat kolom komentar akun penyebar. Dan gerakan ini bukan alat membungkam kritik yang sah: kritik berbasis fakta tetap harus dilayani dengan argumen, bukan diserbu.

## 2. Satir Untuk Pemerintah & Mesin Buzzer

*Bagian ini opini/satir, bukan pemberitaan. Ditulis agar warga bisa tertawa — lalu mikir.*

- Pemerintahan yang kuat tidak butuh pasukan komentar. Kalau satu kebijakan perlu 10.000 akun buat bilang “bagus bagus bagus”, yang sebenarnya sedang diuji bukan kebijakan — tapi rasa percaya publik.
- Buzzer itu seperti tukang parkir di mal: tidak membangun malnya, tidak membayar listriknya, tapi selalu muncul sambil bilang “sini, saya bantu, bayar ya”. Bedanya, bayarnya pakai engagement kita.
- Setiap kali warga dikasih jempol untuk memuji, tapi dikasih pasal untuk mengkritik, jangan heran kalau warga belajar cuek. Cuek itu kadang bukan apatis — cuek itu respon terakhir setelah didengar dianggap gangguan.
- Karhutla tidak padam dengan tagar. Banjir tidak surut dengan narasi. Harga naik tidak turun karena ada yang bilang “sabar”. Fakta di lapangan tidak bisa di-scroll lewat.
- Kalau pemerintah mau dilike, tugasnya bukan menyewa keramaian. Tugasnya bikin warga rela memuji tanpa disuruh.

**Slogan situs (siap pakai di poster/share):**

> Salam cuek. Saya tidak komen, tidak share, tidak quote.
> Engagement saya saya alihkan ke fakta: karhutla, banjir, harga, dan kebijakan yang berdampak ke rakyat.
> Yang provokatif saya lewati. Yang bermanfaat saya dukung.
> #CuekinBuzzer

## 3. Rancangan Web — SvelteKit + TailwindCSS → GitHub Pages

### 3.1 Tujuan situs

1. **Edukasi 60 detik**: pengunjung paham gerakan dalam sekali scroll.
2. **Panduan praktis**: daftar Boleh/Jangan yang bisa dibagikan (screenshot / copy).
3. **Teks siap salin**: template komentar, postingan, dan pesan WA untuk siaran grup.
4. **Sumber terverifikasi**: setiap klaim faktual terhubung ke pemberitaan sumber tepercaya.
5. **Ringan & cepat**: static site, tanpa backend, siap di GitHub Pages.

### 3.2 Tech stack

| Layer | Pilihan | Alasan |
|---|---|---|
| Framework | **SvelteKit** (Svelte 5) | SSR/SSG, komponen reaktif ringan |
| Styling | **TailwindCSS v4** | Cepat, konsisten, build kecil |
| Adapter | **@sveltejs/adapter-static** | Output HTML murni untuk GitHub Pages |
| Bahasa | TypeScript | Aman untuk data & komponen |
| Hosting | **GitHub Pages** | Gratis, via GitHub Actions |
| Repo | `nyawit-dev/cuekin-bazer` | Publik |
| Base path | `/cuekin-bazer/` | Wajib untuk project Pages |

### 3.3 Struktur halaman

```
/                         → Hero + manifesto + statistik gerakan
/panduan                  → Boleh/Jangan interaktif (accordion + checklist)
/fakta                    → Timeline & ringkasan berita dengan sumber
/satir                    → Halaman opini/satir (tegas, tapi bukan fitnah)
/salin                    → Template teks siap copy (WA, IG, Threads, X)
/sumber                   → Daftar pranala berita & rujukan
/tentang                  → Disclaimer, etika, cara berkontribusi
```

```
cuekin-bazer/
├── .github/workflows/deploy.yml   # build + deploy GitHub Pages
├── src/
```

### 3.5 Data model (static JSON, tanpa DB)

```json
// news.json
{ "id": "windah-2026-11-05", "tanggal": "2026-11-05", "judul": "...", "sumber": "Instagram @windahbasudara", "ringkasan": "...", "url": "..." }

// rules.json
{ "kategori": "JANGAN", "teks": "Jangan screenshot konten buzzer...", "alasan": "Penonton penasaran akan datang ke akun aslinya." }

// templates.json
{ "platform": "WhatsApp", "judul": "Salam cuek", "teks": "..." }
```

### 3.6 Desain

- **Tema**: gelap, tegas, poster-protes. Background `#0a0a0a`, aksen merah `#e11d48` + hijau `#22c55e` (stop vs go).
- **Tipografi**: sans-serif bold untuk headline (mis. Inter / Plus Jakarta Sans), mono untuk tagar & share-text.
- **Komponen kunci**: sticky nav, hero manifesto, kartu statistik, accordion Boleh/Jangan, tombol Copy dengan feedback “Tersalin!”, kartu sumber dengan ikon media.
- **Aksesibilitas**: kontras AA, fokus visible, tombol accordion dengan `aria-expanded`, teks alternatif gambar.
- **Performa**: tanpa gambar berat, font subset, target Lighthouse ≥ 95.

### 3.7 SEO & share

- Open Graph + Twitter card per halaman.
- `og:image` poster 1200×630 bertuliskan slogan.
- Judul & deskripsi unik per route; `sitemap.xml` sederhana untuk 6 halaman.

### 3.8 GitHub Pages deployment

```yaml
# .github/workflows/deploy.yml (gambaran)
- uses: actions/checkout@v4
- uses: actions/setup-node@v4        # Node 22
- run: npm ci && npm run build       # adapter-static → build/
- uses: actions/configure-pages@v5
- uses: actions/upload-pages-artifact@v3   # path: build/
- uses: actions/deploy-pages@v4
```

Settings repo: **Settings → Pages → Source: GitHub Actions**. URL hasil: `https://nyawit-dev.github.io/cuekin-bazer/`

> Catatan path: karena ini *project* Pages (bukan user site), `svelte.config.js` harus pakai `paths: { base: '/cuekin-bazer' }` — kalau tidak, semua aset 404.

### 3.10 Etika & batasan

- Tidak memuat data pribadi, tidak tracking pengunjung.
- Satir hanya untuk kebijakan & praktik komunikasi publik — bukan menyerang individu dengan tuduhan tak berdasar.
- Semua kutipan berita wajib ada sumbernya; koreksi diterima lewat Issue.
